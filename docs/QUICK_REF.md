# 参数与状态速查

更新时间：2026-09-07

| 参数 | 页面默认值 | 白话说明 |
| --- | ---: | --- |
| 配对成本上限 | `0.99` | 两边预计平均成本超过它就不补 |
| 单笔金额 | `$2` | 单次最多花多少钱 |
| 本次总上限 | `$10` | 本次累计最多使用多少钱 |
| 最多订单 | `50` | 防止无限下单 |
| 运行时间 | `5` 分钟 | `0` 为一直运行到手动停止 |
| 挂单保留 | `15` 秒 | 超时后撤掉重新算 |
| 决策间隔 | `0ms` | 两次计算至少间隔多久 |
| 反向撤单 | `0` 基点 | 价格反向多少后撤单 |

页面：`http://127.0.0.1:18765/system-dashboard.html`（都柏林 SSH 隧道）。

## 状态词

- **模拟运行中**：读取真实行情，使用纸面资金。
- **安全模式**：交易任务未运行或实盘未解锁。
- **未结算**：官方结果尚未出现，不能确认收益。
- **暂无实时数据**：采集器离线或数据已过期。
- **账户未配置**：服务器没有可用签名凭据。
- **实盘未解锁**：即使页面选择实盘，也不会提交真钱订单。
