# Agent 工作与协作约定

日期：2026-09-17。版本：v8。主线：[BTC五分钟反转开发规划](REVERSAL-DELIVERY-PLAN-2026-09-17.md)。做市终止，旧版“所有策略暂停”要求失效。

## 分工

| Agent | 独占责任 | 文件范围 |
| --- | --- | --- |
| 主Agent | 接口、API/配置/投影、集成、真实联调、发布及文档 | `scripts/dashboard/`、`docs/`、发布清单 |
| 策略Agent | 70/75、四阶段、恢复输入输出、相应测试 | `engine/src/strategies/btc-reversal*` |
| 执行Agent | 核心类型、订单身份/恢复、费用/资金、换场、结算 | `engine/src/platform/`、`src/live/`、`src/cli/platform.ts`及测试 |
| 前端Agent | 普通用户配置、反转状态、订单分页、页面验证 | `web/src/`及测试 |
| 复核Agent | 实现后接替空闲槽位，独立查错 | 只读，问题退回原负责人 |

`engine/`指`_external/btc-5m-market-trading-bot/`。最多主Agent加三条实现线并行。本轮评估由strategy_spec、platform_integration、frontend_reversal_plan完成，实施责任按上表分配。

## 工作方式

1. 先读最新规划、技术评估、源码和工作区改动。桌面说明和历史报告不是当前运行事实。
2. 主Agent定契约和文件所有权；三条线并行。engine共享类型由执行Agent修改，其他人不同时编辑。
3. 不覆盖他人的未提交内容，只提交本任务文件；凭据、认证头、私有备份不入Git。
4. 发现矛盾立即修正规则和任务树，独立能做的继续做，不等罕见行情几天。
5. 运行短时功能/故障测试、受影响回归、类型检查和构建，然后做已授权额度内的小额真实接口验证。不增加回测、连续paper、多日样本或午夜等待。
6. 独立复核实际代码；没有真实回报不造成交，没有到账不写已完成。未发生的线上分支如实说明。
7. 每批更新本地、Git、服务器清单及任务状态；不反复询问已授权开发操作。

## 执行边界

策略通过StrategyPlugin输出意图；底座负责签名、资金、订单及结算。70/75实盘互斥、最多四阶段、相反跨价加阶段、反转不撤旧单；未知提交不能盲目重下。

行情/用户回报走事件热路径。REST全量账户、历史、页面刷新和结算轮询走后台。未知提交或账本差异定向恢复，避免重复单，也不把每笔下单变成多轮远程串行检查。

行情失效只暂停新触发，正常旧单保留；到截止或用户选择停止并撤余量时撤单。停止新增、撤完工作单、清空持仓、赎回到账是不同状态。

## 资金与发布

旧50美元本金/30美元日损用于小额接口验证，原版两套四阶段都超额度，不能暗改为桌面纸面300美元。开发不等额度结论，完整原版启动须有明确有效资金配置。预留与实际费用分开；日损停止不是已有持仓损失保证。

部署前备份程序与配置，核对源码/构建/哈希/服务。回退程序不覆盖新成交后的账本，不自动重启旧做市；完整备份先恢复独立副本，再按交易所事实恢复交易状态。
