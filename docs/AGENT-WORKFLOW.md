# Agent 工作与协作约定

日期：2026-09-16
版本：v6
适用范围：公共交易底座审查、文档整理、控制台和运维。策略接入与参数调优暂停。

## 1. 总规则

所有 Agent 共用一个工作区。先读当前源码、任务树和本文件，再修改自己负责的文件。不得覆盖其他 Agent 的未提交改动，不得把历史证据改写成当前事实，不得在文档中复制私钥、API secret、服务器密码或认证请求头。

每项工作都要有：输入版本、负责人、文件范围、验证命令、结果和下一步。发现与规划不一致时先记录事实，再同步修正文档和任务树；不继续沿用旧规划。

## 2. 角色和责任

| 角色 | 当前责任 | 主要文件 |
|---|---|---|
| 主 Agent | 统筹范围、拆任务、合并结果、发布、回退和最终事实状态 | `docs/`、发布清单、任务树 |
| 执行 Agent | 审查订单状态、资金预留、账户/用户流、Polymarket 适配器、关闭和恢复 | `_external/btc-5m-market-trading-bot/src/platform/`、`src/live/` |
| 数据 Agent | 审查行情深度、时间戳、来源新鲜度、账户数据范围和历史证据 | `src/live/feeds/`、`scripts/dashboard/`、数据契约 |
| QA Agent | 编写故障用例，复跑测试、类型检查、构建、差分检查和发布核验 | `tests/`、`*.test.ts`、验证清单 |
| 产品/API Agent | 检查六页页面、任务树、接口状态和用户可见数据；不伪造在线数值 | `web/`、`docs/task-view.json`、`docs/API.md` |
| 量化 Agent | 当前仅维护历史研究索引；不接入策略、不改策略参数 | `docs/evidence/`、`docs/research/` |

策略 Agent 在本阶段不运行。任何策略代码变更必须等待底座阶段恢复，并通过独立策略审查。

## 3. 工作顺序

1. **盘点**：读取任务树、当前状态页、目标模块和最近提交，确认是否有未提交改动。
2. **审查**：先写可复现测试或最小故障用例，再判断是否需要改代码。
3. **实现**：只改责任文件；接口变化必须同时更新类型、适配器、测试和文档。
4. **验证**：至少运行受影响模块测试、`npm run typecheck`、`npm run build`；跨模块改动再运行全套测试和 Python 验证。
5. **复核**：代码改动交给独立复核 Agent 检查状态、资金、权限和回归风险。
6. **交付**：更新当前状态、规划和 `task-view.json`，再提交、推送和按发布清单部署。

## 4. 平台与策略边界

公共平台可以独立运行，即使没有策略也能发现市场、接收行情、读取账户、保存状态和输出遥测。策略只依赖 `StrategyPlugin`：读取事件和只读 `StrategyContext`，返回 `submit/cancel/replace` 动作。策略不能直接调用 CLOB client、写账本、释放预留、结算资金或修改风险限制。

旧 `Engine`、`MakerSession`、`PairCost` 和历史 `stableLive/target_clone` 入口属于兼容路径。它们不得被描述为新平台的默认策略，也不得在本阶段接入新 CLI。

## 5. 低延迟要求

行情和认证用户事件进入内存热路径；成交先更新账本并触发策略事件。REST 读模型、历史归档和慢账户查询只能后台合并，不得作为补单、撤单或风险事件的等待条件。每次延迟必须区分签名、HTTP ACK、用户事件、REST 可见、成交和本地处理时间。

## 6. 状态与资金安全

下单前先持久化资金/份额预留；未知 ACK 或未知撤单不释放预留。重复成交按 `tradeId + orderId` 去重。重启发现活动订单必须先核对，不能直接继续下单。持久化失败、行情过期、账户核对失败和停止后残单都应停机或保持未解锁。

## 7. 三段同步和回退

三段是本地源码、Git 远端和服务器发布。每次发布记录源码 SHA、构建产物、配置版本、服务状态和验证证据；部署前备份要替换的文件，部署后逐项核对。回退只恢复本批文件和程序版本，不覆盖订单、账本、风险状态或用户未提交改动。

## 8. 当前暂停项

- 不接入 `pair-cost`、`stableLive` 或任何新自动做市策略。
- 不根据 paper PnL 或参考地址交易记录冻结默认参数。
- 不启动连续自动实盘，不改变 `live_unlocked=false`。
- 不把原子账户、复杂审计或历史全量归档写成当前唯一阻塞；按实际用途后置。

策略恢复的入口是 [自动做市系统交付规划](STRATEGY-DELIVERY-PLAN-2026-09-13.md) 的 P4-P6，并需要主 Agent 更新本文件和任务树。
