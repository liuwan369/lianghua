# Agent 工作与协作约定

日期：2026-09-18。版本：v12。主线：[BTC五分钟反转开发规划](REVERSAL-DELIVERY-PLAN-2026-09-17.md) v2.4。当前发布 `ef15ada`；做市终止，只维护一个可配置的 BTC 五分钟反转实盘系统。

## 分工

| Agent | 独占责任 | 文件范围 |
| --- | --- | --- |
| 主Agent | 共享接口、API/配置/投影、集成、任务树、瘦身、发布及文档 | `scripts/dashboard/`、`config/`、`docs/`、发布清单 |
| 策略与账户Agent | 单一可配置反转逻辑、冲突方向状态、活动/待到账/历史残留分类及测试 | `engine/src/strategies/btc-reversal*`、账户分类模块 |
| 执行热路径Agent | 原子双边行情、快买卖一、订单身份/恢复、WAL、费用/资金、换场、结算 | `engine/src/platform/`、`src/live/`、`src/cli/platform.ts`及测试 |
| 后台与前端Agent | 延迟事件、当前运行、系统资源指标、普通用户页面及验证 | `scripts/dashboard/` 中指定文件、`web/src/`及测试 |
| 复核Agent | 实现后接替空闲槽位，独立查错 | 只读，问题退回原负责人 |

`engine/`当前指`_external/btc-5m-market-trading-bot/`，目录迁移在功能修复后执行。最多主Agent加三条实现线并行。共享接口由主Agent确定，同一文件只能由一条工作线修改。

本轮接续分工：执行热路径 Agent 修复 WebSocket 解析失败、场末精确定时和官方订单状态三项 P1；主 Agent 按依赖删除旧 maker 源码、旧 pm-r25 配置和无用入口；后台与前端 Agent 核对行情投影、展示和 API；复核 Agent 检查每批差异与回归。生产入口 live-only 已完成，旧源码物理清理和真实 `[5,5,5,5]` 验证仍未完成。

## 工作方式

1. 先读最新规划、技术评估、源码和工作区改动。桌面说明和历史报告不是当前运行事实。
2. 主Agent定契约和文件所有权；三条线并行。engine共享类型由执行热路径Agent修改，其他人不同时编辑。
3. 不覆盖他人的未提交内容，只提交本任务文件；凭据、认证头、私有备份不入Git。
4. 发现矛盾立即修正规则和任务树，独立能做的继续做，不等罕见行情几天。
5. 运行保存帧回放、短时功能/故障测试、受影响回归、类型检查和构建；真实交易由用户发起，Agent只读核对实际结果并修复软件。不增加回测、连续paper、多日样本或午夜等待。
6. 独立复核实际代码；没有真实回报不造成交，没有到账不写已完成。未发生的线上分支如实说明。
7. 每批更新本地、Git、服务器清单及任务状态；不反复询问已授权开发操作。

## 执行边界

策略通过StrategyPlugin输出意图；底座负责签名、资金、订单及结算。一个实例最多按用户配置的阶段数运行（历史模板通常为四阶段），相反跨价才增加阶段，反转不撤旧单；未知提交不能盲目重下。

交易行情/用户回报走事件热路径。停机总览行情由独立公共 CLOB Market WebSocket 投影提供，不读取账户秘密、不具备下单能力；REST只做 Gamma 市场发现和必要规则读取。全量账户、历史、页面刷新和结算轮询走后台。未知提交或账本差异定向恢复，避免重复单，也不把每笔下单变成多轮远程串行检查。

独立行情投影按真实源时钟判断新鲜度，并校验价格、token、场次和连接状态；最多容忍 1 秒源时钟领先，页面读取和文件心跳不能给旧行情续期。已完成 `1789710000` 到 `1789710300` 的跨场只读验证，此结果不代替策略订单换场与结算验证。

Market WebSocket 的同一双边批次必须原子应用后只调用一次策略；`best_bid_ask` 快事件必须推进本侧时间、序号和权威买卖一。User WebSocket、订单 HTTP 与后台对账可并行，同一市场状态机按接收顺序串行，同一经济订单的提交、查回、撤单和重试严格串行。不得用固定采样、debounce 或只保留最后一帧代替完整事件处理。

下单前只允许一次包含阶段、资金预留、配置版本和已签订单身份的最小 WAL 耐久提交。耐久失败不得发送；未知 ACK 按已保存身份查回，不重新生成经济订单。行情应用、策略判断、WAL、签名、HTTP ACK、用户回报和撤单分别计时，不能把交易所等待或排队成交算成本地代码延迟。

行情失效只暂停新触发，正常旧单保留；到截止或用户选择停止并撤余量时撤单。停止新增、撤完工作单、清空持仓、赎回到账是不同状态。

## 资金与发布

历史 `$50` 本金和 `$30` 日损只是已撤销的讨论假设，不是代码常量、测试上限或上线门槛。70/75 只是可编辑参考模板；用户填写的预算、阶段数和日内停止条件在每场按实时余额、最低有效金额、费用和未结算占用动态计算。预留与实际费用分开；日内停止也不是已有持仓损失保证。

部署前备份程序与配置，核对源码/构建/哈希/服务。回退程序不覆盖新成交后的账本，不自动重启旧做市；完整备份先恢复独立副本，再按交易所事实恢复交易状态。

仓库瘦身先生成生产依赖图并解除引用，再删除旧做市、paper、回测、研究入口、旧网页和过时文档。真实订单/成交/充值/赎回/结算证据、账户秘密、当前未提交修改和至少一个已验证回退版本不得随瘦身删除。
