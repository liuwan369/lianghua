# 当前进展

更新时间：2026-09-17。平台底座接口化完成，正在进行代码审查和事实文档整理；策略暂停，自动实盘关闭。

本批完成控制台平台入口、运行身份恢复、独立日志、运行和订单投影以及前端观察状态。当前前端总览、自动交易、策略、收益、设置和任务视图已同步，市场/订单独立入口删除，订单模块归入自动交易。服务器验证及同步结果见 [前端重构发布记录](evidence/2026-09-17/frontend-refactor-release.md)。

## 已完成

- `TradingPlatform`、`TradingCore`、`StrategyPlugin`、`PaperGateway`、Polymarket 适配器和 `PlatformStore` 已提交。
- 公共平台支持 BUY/SELL、多订单、部分成交、撤单、替换、去重、资金/份额预留和风险停机。
- L2 档位、真实 tick、交易所时间、本机接收时间、处理耗时和消息年龄进入平台契约。
- 实盘网关已增加完整且新鲜盘口、认证用户流连续性的下单门禁。
- 修复撤单后迟到成交预留、终态订单复活、深度顺序、订单 ID 冲突、paper 流动性重复消耗、二元结算输入和崩溃恢复快照问题。
- 追加修复 paper 撤单成交排序、账户快照倒退、终态迟到成交、重连后的完整账户核对、保留 `external` 命名空间和完整 L2 健康时间。
- 本轮复核修复盘口首档与深度不一致、断线期间纯撤单恢复、取消单账户快照成交增量、停止前用户事件冻结，以及 paper 撤单/成交回调竞态。再次独立复核发现的失败核对污染账本、FAK 剩余量再成交和并发撤单提前回报也已修复；前端 72 项、类型检查和构建通过，其他语言测试沿用最近完整基线。
