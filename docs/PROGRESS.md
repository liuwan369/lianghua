- 用户频道或主行情频道掉线即进入最高优先级撤单停止；实盘盘口超过 `250ms` 禁止下单；成交早于 HTTP ACK 时可缓存并在订单 ID 登记后重放；撤单响应不明确时保留本地订单状态并报错。
- HTTP ACK 返回的成交编号已接入只读后台核对；完整盘口之后到达的旧时间戳增量会被丢弃，避免本地订单簿倒退。
- ACK 状态未知时已加入失败关闭核对：保持用户 WebSocket、至少观察 5 秒并全量查询当前市场成交、重建本场仓位，并连续确认没有残留挂单；核对后仍停止，不自动恢复真钱下单。
- 成交记账已统一改为平台 trade 事件，避免 order update 与 trade 同时到达造成重复仓位；未使用的逐交易所明细已从策略队列剔除。
