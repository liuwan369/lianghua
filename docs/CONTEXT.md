## 策略和运行风险

maker 决策、费用预算与执行按每个 token 的真实 tick 向下量化，缺少 tick 时拒绝。最低委托不能自动扩大策略批准数量。挂单占用、部分成交剩余量、待终态吃单、迟到回报和停止最终对账已有回归约束。

当前源码通过 `strategy.ts` 的 `hedgeLimit()` 在候选与最终份数计算中统一补腿成本政策：常规从配置基础值出发，超时/尾盘可进入应急门槛。旧文档“最终始终为 0.99”的描述已不适用；资金、份数及最坏损失检查仍会限制实际提交。新自适应方案尚待实施，不能把当前政策参数视为已校准最优值。
