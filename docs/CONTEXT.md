## 策略和运行风险

maker 决策、费用预算与执行按每个 token 的真实 tick 向下量化，缺少 tick 时拒绝。最低委托不能自动扩大策略批准数量。挂单占用、部分成交剩余量、待终态吃单、迟到回报和停止最终对账已有回归约束。

`target_clone` 的动态补腿最终按 `hedgePairCostCeiling=0.99` 检查；紧急候选阈值不保证最终可成交或必然平仓。补腿成本超限、预算不足或残余数量不足最低份数时仍可能单边持仓。未验收长期收益、真实队列概率和完整退出策略。

常驻增量盘口、账本空闲跳过及同机历史分析资源隔离已部署。约 20 秒样本中控制台 CPU 用时从 12.68 降至 3.76 秒；账户检查从 46.33 秒/504 变为 23.817 秒/200。历史分析限额为 0.2 核，仍扫描 24 小时。SDK 冷启动、长时间负载稳定性及高 steal 仍待处理；CPU 积分与 credit 模式因 IAM 只读权限不足尚未核实。
