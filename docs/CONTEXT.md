## 唯一目标

维护一个普通用户能操作的 Polymarket BTC Up/Down 5 分钟双边动态补仓系统。先把真实公开数据、纸面执行、风险和页面做可靠，再用极小额真实订单完成最后校准。

## 已确认事实

- 研究地址：`0x3048d65321be3497164cdfc2996f94f98a2e7537`。
- 该地址主要在 BTC 5 分钟市场双边买入，成交后动态补较轻的一边；不是每笔都把 Up+Down 锁在 1 美元以下。
- 我们的策略逻辑已实现：根据当前赔率、平均成本、库存和资金动态计算补仓量；无法修复时停止追价。
- 实时挂单还会结合公开买方深度、主动卖单速度、挂单时长和波动估算成交概率；概率下降或关键数据缺失时自动撤单/停止新挂单。
- 当前主节点是 AWS 都柏林，东京只作历史和延迟对照。
- 当前页面有交易、账户、配置、订单四个入口；用户可自行检查并保存服务器账户配置。
- 公开行情、公开成交、BTC 行情和链上日志是真实数据。
- 纸面挂单、成交概率、排队位置和模拟盈亏是模型结果。
- 没有真实账户证据时，返佣和奖励按 0 计算；没有官方结算结果时保持未结算。
- 官方已确认：自建 bot/MM bot 使用 Relayer API Key；Builder Key 不是必需项；Session Key 目前是仅向选定合作方开放的 Beta 功能。
- 2026-09-07 只读核对网页登录账户：账户地址为 `0xA693a0E0e40BDeC3d9d4a40bD4D087A5cECFD7cd`，可用于交易的现金为 `$15.71`，当时暂无持仓。网页登录状态不等于都柏林服务器已经获得交易授权。
- `$1` 在网页“一键买入”中是主动成交的现金金额；本系统当前策略使用限价挂单，BTC 5 分钟市场公开参数显示最小 5 份，因此只有挂单价不高于约 `$0.20` 时，单笔 `$1` 才能满足最小份数。
