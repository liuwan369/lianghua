更新时间：2026-09-16。正式入口为 **https://34-242-206-196.sslip.io/console/**。当前公共交易底座可独立运行，策略接入暂停；服务器交易停止、模式为 `paper`、`live_unlocked=false`。

## 页面能力

| 页面 | 当前可用 | 当前缺口 |
| --- | --- | --- |
| 总览 | 节点状态、行情、来源时间、运行摘要、paper 启停 | 完整五档深度和同订单端到端延迟 |
| 自动交易 | 纸面运行控制、盘口有效性、运行事件 | 策略动作、实盘启停和完整生命周期展示 |
| 市场 | 当前市场、双 token 买一/卖一、来源与新鲜度 | 五档容量和长期在线统计 |
| 订单 | 运行事件、已接入的账户订单/成交视图、来源切换和导出 | 完整持久化的真实逐委托历史 |
| 收益 | 可用运行摘要、已关闭持仓报告盈亏、已知费用/奖励来源 | 钱包最终净额、完整费用和奖励到账覆盖 |
| 设置 | 账户检查/保存、九项平台配置保存 | 策略参数、自动调参和实盘控制 |
| 任务视图 | 中文功能树、状态颜色、负责人和下一步 | 只显示已同步的任务数据，不替代代码验收 |

`--` 表示当前没有有效来源，不代表零。paper 成交、持仓和 PnL 是模拟结果，不能当作真实收益。

## 配置边界

可以保存的字段是 `order_usd`、`maker_life_sec`、`mode`、`duration_min`、`max_total_usd`、`max_orders`、`pair_cost_max`、`decision_interval_ms` 和 `defensive_cancel_bps`。其中 `pair_cost_max`、`decision_interval_ms`、`defensive_cancel_bps` 仍属于兼容运行字段；策略暂停期间不把它们解释为新策略默认值。

保存配置只作用于下次 paper 启动，不启动策略，不解锁实盘。选择 `live` 也不会绕过 `live_unlocked=false`。

当前“开始模拟”仍是旧引擎入口，并非新平台的无策略观察模式。策略暂停期间保持交易停止；控制台启停和状态投影迁移完成后才切换入口，进度见任务 UI-00。

## 账户操作

“检查”是只读验证；“保存账户”才会写入服务器。私钥不要粘贴到聊天或日志。检查成功不等于真实下单验收，保存账户也不会自动授权、下单或转账。页面不回显秘密字段。

## 数据和运行状态

行情必须同时满足来源有效、双 token 有效和新鲜度门禁。断线、过期或缺一侧时显示不可用，不拼接旧市场价格。平台订单接口与旧兼容引擎事件是两条边界，页面不会把运行事件冒充完整真实订单生命周期。

完整缺口、测试基线和恢复条件见 [当前系统状态](CURRENT-STATUS.md)、[交付状态](DELIVERY.md) 和 [任务视图](task-view.json)。
