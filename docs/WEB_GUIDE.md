# 控制台使用说明

更新时间：2026-09-16。正式入口为 **https://34-242-206-196.sslip.io/console/**。本文对应本批源码中的平台观察接入，部署与线上核对由主代理另行完成；不能据此认定公网已更新。当前公共交易底座可独立运行，策略接入暂停。

## 页面能力

| 页面 | 当前可用 | 当前缺口 |
| --- | --- | --- |
| 总览 | 节点状态、行情、来源时间、平台观察启停、模拟现金/持仓/活跃委托/风险 | 完整五档深度和同订单端到端延迟 |
| 自动交易 | 平台观察控制、未加载策略标识、盘口有效性、运行事件 | 策略动作、实盘启停和完整生命周期展示 |
| 市场 | 当前市场、双 token 买一/卖一、来源与新鲜度 | 五档容量和长期在线统计 |
| 订单 | 运行事件、已接入的账户订单/成交视图、来源切换和导出 | 完整持久化的真实逐委托历史 |
| 收益 | 可用运行摘要、已关闭持仓报告盈亏、已知费用/奖励来源 | 钱包最终净额、完整费用和奖励到账覆盖 |
| 设置 | 账户检查/保存、九项兼容配置保存及实际生效范围 | 策略参数执行、自动调参和实盘控制 |
| 任务视图 | 中文功能树、状态颜色、负责人和下一步 | 只显示已同步的任务数据，不替代代码验收 |

`--` 表示当前没有有效来源，不代表零。paper 成交、持仓和 PnL 是模拟结果，不能当作真实收益。

## 配置边界

可以保存的字段是 `order_usd`、`maker_life_sec`、`mode`、`duration_min`、`max_total_usd`、`max_orders`、`pair_cost_max`、`decision_interval_ms` 和 `defensive_cancel_bps`。**平台观察只应用 `mode` 和 `duration_min`**；其余七项保留在已保存配置中，控件标记“可保存，平台观察不应用”，不会传给新平台。未修改字段和尚未提交的编辑值不会因后台刷新而丢失。

保存不会启动或改变当前运行。前端和版本化启动接口目前只启动 `paper`，选择并保存 `live` 不能从页面启动。平台观察不加载策略、不自动下单。新建 paper 运行使用平台默认 `$1000` 模拟现金和平台风险默认值，与真实账户余额及实盘 `$50/$30` 边界分开。

本批入口为“启动平台观察 / 停止平台观察”，调用公共 `TradingPlatform`。已有旧运行显示“旧引擎纸面”，其停止按钮也保留此标识。运行时长为 `0` 表示不按配置时长退出；本批仍在已订阅市场全部到期时停止，尚未自动轮换到下一场。

## 账户操作

“检查”是只读验证；“保存账户”才会写入服务器。私钥不要粘贴到聊天或日志。检查成功不等于真实下单验收，保存账户也不会自动授权、下单或转账。页面不回显秘密字段。

## 数据和运行状态

行情必须同时满足来源有效、双 token 有效和新鲜度门禁。断线、过期或缺一侧时显示不可用，不拼接旧市场价格。平台订单接口与旧兼容引擎事件是两条边界，页面不会把运行事件冒充完整真实订单生命周期。

运行摘要的“平台模拟现金 / 平台持仓 / 活跃委托 / 平台风险”来自当前运行的 `stats.runtime`；真实账户余额和持仓继续在原账户区域显示，不互相填补。摘要同时列出来源、运行编号、采集时刻和数据年龄。只有运行编号匹配、投影就绪、快照仍有效且进程运行中，才显示当前平台数值；过期、停止或缺失时清空当前值，最终快照标作历史。总览和任务页每秒核对有效期，重复刷新接口不会给旧快照续期。
