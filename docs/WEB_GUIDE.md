# 页面使用说明

更新时间：2026-09-07

## 打开页面

当前公网页面（需要登录）：

```text
https://34-242-206-196.sslip.io:80/system-dashboard.html
```

备用地址：先运行 `scripts/start-dublin-dashboard-tunnel.ps1`，再打开 `http://127.0.0.1:18765/system-dashboard.html`。

公网已启用有效 HTTPS 证书、登录保护和请求限速。Lightsail 当前未开放 443，所以临时使用 HTTPS 的 `:80` 端口。

## 交易

- 显示当前 BTC 5 分钟市场、Up/Down 买卖价和两边成本。
- 点击“开始模拟”后，真实行情驱动纸面策略。
- 显示模拟挂单、成交、撤单、成交额、持仓和结算盈亏。
- 点击“停止并撤单”会停止纸面任务；纸面模式没有交易所真实挂单。

## 配置

- **最高配对成本**：Up 和 Down 的预计平均成本上限。
- **单笔最多**：一次订单最多使用金额。
- **本次最多使用**：本次运行累计资金保险丝。
- **最多订单数**：达到后停止新增订单。
- **运行分钟**：填 `0` 表示一直运行，直到手动停止。
- **挂单最长保留**：到期撤单并按新盘口重新计算。
- **决策间隔**：限制策略重新判断频率。
- **价格反向撤单**：市场反向达到阈值后撤报价。

保存配置后，下一次启动使用。页面参数不能绕过服务器的实盘锁。

## 订单

按市场汇总成交笔数、成交额、Up/Down 数量、成本和结算结果。最近明细限制显示条数，避免成交多后页面无限变长。

## 数字口径

- “成交额”是纸面成交金额，不是账户扣款。
- “收益”只在官方市场结果可用后结算；未结算不猜赢家。
- 模拟手续费不是逐笔账户账单。
- 返佣和奖励没有真实账户记录时按 0。
- 纸面成交由公开成交触发，但不知道真实排队序号，不能保证实盘能成交。
