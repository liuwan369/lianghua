# 页面使用说明

页面：`https://13-115-254-211.sslip.io:8765/system-dashboard.html`

## 交易

这里是唯一的启动位置。能看到：

- 东京盘口是否在线；
- 当前自动选择的 BTC 5 分钟市场；
- Up/Down 买一、卖一和合计成本；
- 本次挂单、成交、撤单、成交额和收益。

点击“开始模拟”才会启动纸面引擎。点击“停止并撤单”会停止本地任务；纸面模式没有真实挂单。

## 真实账户状态

当前页面即使显示账户余额，也只代表网页只读结果。当前系统仍是纸面模式，没有真实挂单、撤单或成交回报；不要把页面的模拟成交额当作账户扣款。

## 配置

- 最高配对成本：Up 和 Down 合计最多接受的价格。
- 单笔最多：一次订单最多使用的美元。
- 本次最多使用：本次运行累计资金上限。
- 最多订单数：达到后自动停止下新单。
- 运行分钟：填 `0` 表示一直运行，直到手动停止。
- 挂单最长保留：超过时间会撤单并重新判断。
- 价格反向撤单：价格反向达到这个幅度时撤掉报价。

建议先用小额纸面参数观察完整一个 5 分钟市场，再改参数。

## 订单

按市场汇总成交笔数、成交额和结算收益。实时明细只在“交易”页显示最近记录，避免页面堆积几千行。

## 页面数字怎么看

- “成交额”是纸面成交金额，不是账户扣款。
- “收益”只有市场结算后才出现；未结算显示“未结算”。
- 纸面收益不包含已确认的真实奖励，也不代表未来实盘收益。
- 数据断开时页面会清空旧盘口，不会把旧价格伪装成实时数据。
- 如果外部 WebSocket 连接受限，模拟引擎会改用东京只读采集的盘口；这仍是真实盘口，不会伪造价格。没有达到配对成本上限时，系统会等待而不是强行下单。
- 页面显示的模拟成交是公开成交触发后的影子结果，不是账户成交；奖励、返佣和实际排队位置尚未接入。
