入口：[打开控制台](https://34-242-206-196.sslip.io/console/)。更新：2026-09-17，版本 `a9d37cd` 已部署并核对主要代码 hash。检查时系统未运行、实盘开关关闭、策略版本为 0，尚未保存启动；本轮没有真实订单。

## 页面

| 页面 | 用途 |
| --- | --- |
| 总览 | 账户资金、运行状态、持仓/订单及收益摘要 |
| 自动交易 | 当前五分钟场与倒计时、UP/DOWN 价格和盘口档位、阶段进度、持仓、运行原因和分页订单 |
| 策略 | 顶部选择 BTC 五分钟反转，下方分“策略参数 / 运行设置” |
| 收益 | 查看有来源的成本、费用和收益；未到账金额不当作可用资金 |
| 设置 | 账户检查/保存、节点和系统诊断、各环节延迟 |
| 任务视图 | 中文功能树、完成状态、负责人和剩余工作 |

独立“市场”和“订单”页面已删除，数据集中在自动交易页。盘口已有多档展示；订单支持每页 10/20/50 条、当前/全部场次和来源筛选。

## 配置和运行

1. 在“策略”选择 **BTC 五分钟反转**，填写触发价、反转确认价、最高买入价、阶段数及每阶段份额。页面价格单位为美分。
2. 在“运行设置”填写可选的单场资金上限、总资金上限、每日亏损停止线和运行时长。资金项留空不加额外上限，但仍受账户余额约束；时长 0 表示持续运行。
3. 点击“保存策略”。70/75 按钮只是填入可修改的参考价格/份额，不改变预算；保存不会自动下单。价格、阶段和预算下一场生效，时长下次启动生效。
4. 账户检查、服务器实盘开关和保存版本满足后，点击“启动 BTC 反转”。启动失败时按页面具体原因处理；刷新核对已有启动结果，不能把按钮点击当成功。

“暂停新增”保留现有订单和持仓管理；“停止”处理工作单后退出交易进程，已成交持仓及恢复数据保留。关闭网页不会停止服务器。当前运行按钮连接真实策略，不使用做市参数，也不需要编辑 JSON。

## 账户

“检查”只读验证；“保存账户”才写入服务器。资金钱包、Owner、Relayer 和 Builder 各填对应字段，Builder 三项一起填写。同钱包不填写秘密字段表示保留原值，更换钱包不继承原密钥。页面不回显秘密字段，保存账户不会自动交易。

## 数据怎么看

`--` 表示没有当前有效数据，不是零。已停止、过期或其他运行的数据不显示为当前持仓/盘口；刷新页面不会给旧数据续期。策略参数显示已保存版本和当前/下一场版本，未保存输入不会被后台轮询覆盖。

总览的“日内结果 / 停止线”同时显示已核实或暂估。资金变化覆盖尚未追上最新现金读取时会标“暂估”和覆盖时间；确认后的充值提现会从交易结果中剔除。此提示不会要求等待午夜，也不代表系统新增了固定资金限制。

盘口的“数据年龄”来自消息时间，可能含时钟差；下单 ACK、签名、撤单及成交回报分别显示。等待对手方成交的时间不是下单代码延迟。尚无真实运行样本时保留空值，不沿用旧模拟数据作实盘结果。
