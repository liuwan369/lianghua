# 项目说明

更新时间：2026-09-07

## 产品目标

做一个普通用户能操作的 Polymarket BTC Up/Down 5 分钟交易系统：参数可调，页面能看到真实行情、模拟挂单/成交/撤单、成交额、持仓和盈亏；验证通过后才接真实账户。

## 当前范围

- 只做 BTC 5 分钟 Up/Down。
- 支持公开数据采集、历史回放、纸面模拟和受保护实盘代码路径。
- 天气、期权、山寨币和 NegRisk 不在当前产品范围。

## 核心策略

两边都可挂买单。一边成交后，根据两边平均成本、当前赔率、剩余资金和单边库存，计算另一边需要补多少。只有配对成本和风险条件满足时继续；无法修复、临近结束、行情过期或风险超限时撤单停止。

策略目标是让多场的交易净结果加真实奖励后为正，不要求每笔或每场都盈利。当前尚未证明稳定盈利。

## 当前交付级别

- 数据采集：已运行。
- 历史分析：已具备。
- 纸面交易：可操作。
- 真实订单代码：已存在并加保护。
- 真实账户验收：未完成。
- 真钱自动交易：禁止。
