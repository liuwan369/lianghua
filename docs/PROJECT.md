# 项目范围与完成状态

更新时间：2026-09-17。项目主线已改为 Polymarket BTC 五分钟反转交易系统：停止做市开发，复用公共交易底座，按 [反转系统开发规划](REVERSAL-DELIVERY-PLAN-2026-09-17.md) 并行开发策略、执行恢复和前端。用户已授权开发真实反转策略；当前处于备份评估与规划阶段，反转插件尚未实现。

## 分层范围

| 层 | 当前实现 | 当前缺口 |
|---|---|---|
| 行情 | Polymarket WS/REST、双 token、L2 深度、tick、时间和健康状态 | 连续在线样本、控制台五档展示 |
| 平台账本 | BUY/SELL、预留、部分成交、撤单、替换、去重、风险和持久化 | 真实异常生命周期与长期恢复 |
| 账户 | 认证读取、持仓、挂单、成交和结算接口 | 余额/在途/费用/结算/充值提款联合对账 |
| 策略 | `StrategyPlugin` 插件契约和观察插件 | BTC 五分钟反转插件、70/75 互斥配置、阶段持久化和真实验证待开发；旧做市停止 |
| 控制台 | 总览、自动交易、策略、收益、设置、任务视图；配置、无策略平台启停/恢复/投影、账户只读、任务树 | 五档盘口、完整分段延迟和自动换场 |
| 运维 | 都柏林服务、HTTPS、三段发布和回退流程 | 长期负载、告警和无人值守恢复 |

## 完成判定

代码存在、测试通过、接口返回 200、paper 有成交或单笔真实探针，都只能证明一个局部能力。完整自动交易还需要真实订单生命周期、资金核对、停止/恢复和连续运行全部通过；策略盈利另行验收，不能替代平台验收。

当前状态：平台 **PARTIAL / REVIEW**，反转策略 **待开发**，旧做市 **PAUSED**，自动实盘 **CLOSED**。现有页面仍只启动无策略 paper 观察；真实接入按新规划推进，必要功能用快速测试和小额真实订单验证，不增加多日模拟或特殊日期等待。详见 [当前系统状态](CURRENT-STATUS.md)。
