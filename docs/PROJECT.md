# 项目说明

## 范围

只维护 Polymarket BTC Up/Down 5 分钟市场。旧天气、期权、山寨币和 NegRisk 研究已退出当前产品范围。

## 架构

1. 东京采集器通过公开 REST/WebSocket 记录盘口、成交、市场元数据和 BTC 行情。
2. `pm_maker` 提供双边动态补仓和结算回放模型。
3. TypeScript 引擎负责市场发现、订单策略、风控、纸面成交和受保护的真实订单路径。
4. `system-dashboard-server.py` 提供本地页面 API，页面不保存私钥。

## 策略定义

两边都可以挂买单。某一边成交后，优先给另一边补仓；补仓前必须满足配对成本和资金上限。市场临近结束、价格反向或单边库存过大时停止报价。

## 安全

- 默认 `trade_authorization=false`。
- 本地页面只监听本机；东京页面通过受控反向代理访问。
- 私钥只能放在交易引擎环境文件，不能放入网页或日志。
- 真实模式必须有显式确认、服务器解锁和账户预检。
