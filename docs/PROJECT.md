更新：2026-09-17。当前项目是 **Polymarket BTC 五分钟反转交易系统**，做市方向已停止。只有一个策略，70/75 是可编辑参数参考，不是两套策略。

版本 `5166c3d` 已部署到服务器，主要代码 hash 已匹配。本次线上检查为 `running=false`、`live_unlocked=false`、策略配置 `savedRevision=0`：程序已发布，策略尚未保存启动，本轮尚未执行真实订单。

## 系统分工

| 模块 | 已实现 | 当前仍需核对 |
| --- | --- | --- |
| 行情 | BTC 当前/下一场发现、双边 WebSocket、盘口深度、价格精度和新鲜度 | 实际运行中的换场和断线恢复 |
| 交易底座 | 签名、限价单、撤单、订单状态、成交、资金预留、账户读取及恢复 | 本轮真实下单/撤单/成交及费用 |
| 反转策略 | 触发/确认分离、可配置阶段、反转保留旧单、参数版本和阶段恢复 | 小额真实运行与交易所回报一致性 |
| 结算 | 官方结果读取、EOA/Deposit Wallet 赎回、原请求恢复和到账核对 | 本轮真实赢家持仓的赎回回执 |
| 控制台 | 总览、自动交易、策略、收益、设置、任务视图；盘口档位、订单分页、策略保存及启停 | 有真实运行数据时的端到端显示核对 |
| 部署 | 备份、代码发布、主要文件 hash 核对和回退点 | 小额验证后的运行配置及状态同步 |

策略通过 `StrategyPlugin` 输出交易意图；底座处理交易所、账户和资金，后续策略可复用。前端保留普通用户需要的配置，不提供做市参数或 JSON 编辑器。
