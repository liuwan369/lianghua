# 六页前端接入与验收清单

更新日期：2026-09-17。工程 `web/` 的当前源码采用总览、自动交易、策略、收益、设置和任务视图；本清单只描述当前接入边界和剩余闭环，不把页面存在当作功能完成。策略执行仍暂停，策略页只提供配置草稿。

## 设计与模块边界

当前导航为总览、自动交易、策略、收益、设置和任务视图。市场和订单不再作为独立导航：行情属于公共行情底座，在自动交易页展示；订单、成交、撤单和失败记录属于公共执行底座，在自动交易页集中展示。设计基线 `269f8ab` 和 `docs/demo-*` 仅作为视觉参考，不能覆盖当前产品结构。

前端 TypeScript/Vite、Python 控制接口和 TypeScript 交易引擎各自承担展示、配置/读模型、策略/执行职责。版本化配置与 SQLite 运行账本已实现；页面请求不直接重扫整个引擎日志。具体目录和协议见 [架构](ARCHITECTURE.md)、[接口说明](API.md)。

原设计中 `order → order_usd`、`life → maker_life_sec`、`mode → mode`、`duration → duration_min`、`submitted → max_total_usd`、`maxOrders → max_orders` 六项接入服务器保存。新增 pairCost→pair_cost_max、decisionInterval→decision_interval_ms、defensiveCancel→defensive_cancel_bps，合计九项可保存。其余高级字段仍是明确标注的草稿，不能用后端有相近参数来声称已生效。映射见 [设置设计契约](DEMO-SETTINGS-2026-09-09.md)。

| M01 | 切场与故障 | 双边同市场同时间，缺边/过期/未开始明确；切场不串旧报价 |

| E01 | 财务 | 已结算毛损益、实际费用、已到账奖励统一口径；充值提款不计收益，费用不重复扣 |

| S02 | 配置版本 | 并发保存冲突可见，当前运行不被新草稿替换；未实现的热更新不显示可用 |
| S03 | 账户 | 不回显秘密，换账户隔离旧凭据与历史；检查失败不覆盖服务器配置 |
| L01 | 八项遥测 | 行情年龄、盘口处理、策略、签名、下单 ACK、撤单 ACK、成交回报年龄、页面刷新有真实埋点 |

| X01 | 故障恢复 | 超时、403、坏数据、重启、断流、多页及旧事件重放不产生假状态或串账 |
| X02 | 浏览器 | 六页完整设计，输入、保存、导航、窄屏、表格及键盘操作逐项实测 |

## 实施顺序和记录

同账户只读数据和页面映射、纸面控制已接线；继续完成可花余额/挂单占用、完整委托与费用付款对账、全量策略配置及引擎遥测。增量盘口和账本空闲优化已上线；继续减少账户冷启动并完成长期负载验收，保持采集数据完整性。最后完成一轮真实行情纸面闭环与独立的钱包实盘验收。

每项记录版本、场景、预期/实际、证据、通过/失败/未覆盖。只读接口成功不替代交易执行，纸面成交不替代真实成交，自动测试不替代真实浏览器。软件通过不代表策略盈利。

部署前核对服务空闲、构建/API兼容和账本恢复；回滚保持账户文件及新增成交。发布操作见 [部署说明](DEPLOYMENT.md)，当前证据见 [实盘准备度验收](LIVE-READINESS-AUDIT-2026-09-10.md)。

本轮来源与验收边界见 [账户数据接入记录](ACCOUNT-DATA-INTEGRATION-2026-09-10.md)。真实浏览器工具因不能可靠识别 Windows 浏览器 URL 被停止，本轮不记为浏览器验收通过。
