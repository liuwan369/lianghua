# 账户数据接入（2026-09-10）

## 实现与口径

`GET /api/v1/account-data` 返回账户绑定的后台缓存，包含 CLOB V2 抵押余额、未完成委托和成交，以及 Data API 的持仓、已关闭持仓与账户活动。后台常驻 Node 进程，仅使用 GET；不创建 key、不修改 allowance、不下单撤单。账户变更立即清掉旧缓存，网络迟到响应不能写入新账户。

每项返回 `available/complete/items/pages/checked_at/source/error_code`；抵押余额另有 `value`。无账户或失败时允许明确的 stale 空信封。分页有预算和上限，不完整不冒充全历史；上游跨页不是原子快照，`pagination_atomic=false`。后台最短30秒刷新，前端每5秒读取小缓存；浏览器以各板块源时间90秒判断过期，不因重新读取而续鲜。

首页展示抵押资产余额，明确尚未扣除挂单占用，不称为可花余额。真实账户持仓与 paper 运行数据分别标注。已关闭持仓 `realizedPnl` 保留平台口径，不能当作已扣手续费、含奖励、已结算兑付后的钱包净收益。

订单页可切换真实账户订单/成交与运行事件。当前未完成委托和逐笔成交分别展示，Maker 只使用本钱包对应明细，缺少方向保持未知；不会继承对手方方向。筛选、50条分页和当前筛选全部已获取记录的 CSV 导出已连接；导出文本处理公式注入。历史撤单不能由“订单消失”推断，实际费用不由费率冒充。

收益页按 UTC 今日/本月、滚动30天和已获取历史筛选关闭持仓；账户活动中的奖励标签与交易链接仅供核对，不自动计入已到账净收益。真实扣费、奖励付款归属和资格档位仍未完整接入。

纸面控制使用保存版本与请求 UUID，重复点击不重启；不确定网络结果复用请求编号，明确版本冲突后可重新选择新版本。实盘保持锁定。页面刷新埋点统计最近5分钟最新/P50/P95/样本数，其余七环节及同订单整轮反应仍无完整埋点。
