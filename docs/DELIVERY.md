2. 余额、在途订单、持仓、费用、结算和充值提款的持续联合核对。
3. 结算到账、奖励付款和钱包净收益的完整对账。
4. 五档深度、订单生命周期分段延迟和自动调整原因的网页展示。
5. 服务器采集器恢复后的连续延迟、CPU、队列和告警样本。

## 资金边界

小额接口验证不再沿用历史 `$50` 本金或 `$30` 日损；这两个数字不是当前固定限制。系统按用户为这一套策略填写的单场预算、总预算、阶段份额、最大阶段数和可选日内停止条件，结合实时余额、最低有效金额、费用及未结算占用动态判断。70/75 的历史测算只作为可编辑模板参考，不是两个策略、默认预算或上线门槛。验证先使用交易所允许的最低有效金额，本轮备份和文档整理不会新增真实订单。
