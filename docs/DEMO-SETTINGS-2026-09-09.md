# 演示设置改版 · 2026-09-09

本轮仅修改独立演示页的策略参数和运行设置，不修改正式交易服务器或策略执行器。新增 `demo-settings.js/css`，沿用原“账户接入”“系统诊断”和收益/延迟模块。

## 用户流程

1. 基础设置：策略可用本金、每笔金额、单场占用、目标成本及硬上限、未配对份数、挂单时限、补仓等待、开仓与补仓截止。
2. 高级设置折叠：单双档、价差、补仓失败时等待/吃单/减仓、滑点和风险处理损失限制。未验证选项允许保存讨论方案，但阻止演示启动。
3. 运行设置：模式、时长、累计提交金额/订单数、每日亏损停止线、并发场数、断线处理、行情过期、停止持仓处理、配置生效时间。
4. 底部实时检查本金约束、成本上限顺序、时间顺序及最小委托金额。示例市场最低 5 份、价格默认 0.50，可改价格；不是当前平台市场实时数据。
5. 仅把明确列出的非秘密策略字段存入独立浏览器键 `pm-demo-settings-v2`；不保存账户页字段。刷新恢复参数；当前示例价格另校验，不因当前市场不满足而丢弃已保存参数。
6. 演示运行有独立参数快照，运行中保存不改变本次；下一场热更新未实现。取消原固定 $4.90 假成交，启动只显示配置预览，停止不生成真实或虚拟资金变化。

## 明确口径

- 未配对上限的“自动”展示公式为 `floor(单场预算 / 配对硬上限)`，仅为待讨论的演示规则，不是已验证最优库存模型。
- 单笔金额为委托名义金额，费用另需预留；单场占用包含持仓成本、有效挂单与费用预留。
- 累计提交额不因撤单恢复，和并发资金占用不同。
- 亏损停止线是触发动作，不保证最大最终亏损；需要核对已有仓位。停止并撤单不自动卖出持仓，断线不能承诺撤单一定成功。
- 双档、吃单、卖出、多市场、实盘、下一场生效等选项未在本演示执行，均阻止启动。账户额度、真实市场参数、实际费用均为未接入。

## 验证

JavaScript 语法、diff 检查及参数校验逻辑执行通过，包括金额约束、示例 $2 不足最低单、两种库存模式、临近结束先后顺序、无期限运行、非法数值及未验证选项拦截。

独立源码复审发现并修复：低价示例保存后刷新被默认价格误判而丢配置；已禁用字段中的 NaN 仍阻止保存。追加逻辑回归覆盖这两类问题及自动库存、条件校验。未把这些检查称为真实交易验收或完整浏览器视觉验收。
